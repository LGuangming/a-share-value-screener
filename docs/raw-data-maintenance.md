# Independent raw data maintenance

- Workflow **A-Share Raw Data Maintenance** runs after a successful raw-market archive, serialized with the live ingestion and NCAV pipeline. No Tushare calls. A push runs an initial audit only; manual dispatch defaults to audit, with explicit apply input.
- Keep the latest 30 calendar days of full daily_prices and at least 120 distinct observed trading sessions of compact closes. Copy and reconcile recent closes before deleting full rows. Exact SQL row JSONL gzip backups are content-addressed, SHA-256 verified and committed to private object storage before transactional per-date deletions. Pre-2026 SQL dates remain pending separate reconciliation.
- No destructive operations unless latest successful SQL date is covered by complete current-year monthly OHLCV/factor manifests and the production API confirms full current-year coverage and health. Each eligible SQL date also requires all five daily Parquet SHA checks and matching published monthly source hashes. Missing days are retained. Maximum 60 verified dates per run. If fewer than 120 observed trading sessions, skip cleanup.
- Reader snapshot cleanup keeps current and newest previous version plus any files younger than seven days; verify active object and original daily source hashes before removing only obsolete content-addressed reader files. Maximum 50 per run. Never remove original daily data or published completed-year files.
- Reports: 01_raw_data/_maintenance/reports/year=YYYY/run=...json. Track database row counts, allocated relation bytes, object counts/bytes, planned/actual deletions and blocked dates. PostgreSQL DELETE reclaims reusable space; physical allocated bytes need not immediately decrease. No VACUUM FULL or automatic destructive DDL.
- Financial reports, screening results, stocks, job history, ST, and disclosure archives are excluded from retention. If a gate is not ready, publish a blocked report and retain data. Operational failures fail the job; completed date transactions and immutable backups make retry safe. Existing current-year backfill must finish before first cleanup.
