# Archive-first financial refresh

The live financial job first identifies current non-ST main-board prefilter companies with missing or older-than-latest-closed-quarter statement periods. Verified private archive batches are matched to the frozen universe, currency/unit, file SHA-256, counts and symbol membership. Only consolidated type-1 statements with explicit actual announcement date, conservative disclosure before the latest quote day, and valid core values are eligible. Ambiguous latest versions and missing key inputs are skipped, never zero-filled. Insert only absent/newer reporting periods; existing same/newer live periods are preserved. Store source object and SHA provenance in raw JSON. Import is for current live research only, not historical PIT certification or a formal backtest. No historical dates can be imported through archive-first mode.

After import, recompute the backlog and retain the existing capped provider fallback (default 40 companies per scheduled run). Once backlog is empty, poll confirmed disclosures as before. First push triggers archive-only with budget 0 and no Tushare calls. Manual historical asof continues provider-only. If archive validation fails, fail closed before any import, not silently claim full coverage. Recalculate NCAV when live inputs actually change. Track archive targets/batches/selected/inserted/company counts and pre/post backlog in job metrics.
