# Full main-board precomputation

Daily live screening calculates all quoted SH/SZ main-board rows, not only price <=10 and PB<=1.2. ST and financial-sector exclusions remain. The financial archive import, backlog, disclosure refresh, and input fingerprint use the same expanded universe; the initial archive-only run forces NCAV publication after import with no additional Tushare calls. Subsequent scheduled runs keep the existing provider budget. Only selected current-period reports are imported, never full historical archives; verified inserts are batched transactionally. The web reader no longer truncates at 3,000 rows. All price/PB filters, counts, table search, sorting and CSV export are local; blank bounds mean unlimited, missing PB is a separate option. Defaults are 10 and 1.2. Older snapshots may be narrower; UI identifies the old/incomplete scope. Historical candidate changes retain the original default price/PB bounds to avoid artificial entries from widening the scope. Other research views use all published qualified candidates.
